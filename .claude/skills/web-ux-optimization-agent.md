# Web-UX-Optimization-Agent Skills

## enforce_professional_ui

- Checks for consistent spacing, typography, and color usage
- Blocks inline styles or inconsistent design tokens
- Allows centralized theme and design system usage

## validate_loading_states

- Checks that async operations display loading indicators
- Blocks UI changes without loading feedback
- Allows spinners, skeletons, or progress indicators

## audit_error_states

- Checks that failed operations show user-friendly error messages
- Blocks technical error dumps in UI
- Allows clear, actionable error messages

## verify_empty_states

- Checks that empty lists/data show helpful empty states
- Blocks blank screens without guidance
- Allows empty states with calls-to-action

## enforce_accessibility

- Checks for ARIA labels, keyboard navigation, contrast ratios
- Blocks inaccessible interactive elements
- Allows WCAG 2.1 AA compliant UI
